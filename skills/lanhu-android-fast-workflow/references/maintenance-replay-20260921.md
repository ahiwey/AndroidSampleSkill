## 15 个样本的主代理只读回放

这是用已修改流程对已知证据做决策回放，非独立盲测、非重新实现 App。前三类读取缺口以既有验收记录补查；无法取得的新轮次仍保留未知。下表的“观察”是原任务证据，不是优化后重跑 App 的结果。

| 样本 | 已观察输入 | 本轮回放决策与落点 |
| --- | --- | --- |
| R01 维护续做 | 已有规则、工具和上一轮发布基线 | 先比差异，走维护而非导入；三入口只加载职责范围 |
| R02 跨页面配色 | 系统取色与多层旧背景共同影响 | 追窗口、宿主、子页、覆盖层；视觉契约按连续区域核对 |
| R03 指标页续验 | 最新多轮正文空，旧轮称编译成功但未安装 | 标检索缺口；只读现有产物记录，不能提升为当前验收完成 |
| R04 顶部色差返工 | 状态栏相同但相邻背景仍不同 | 接纳用户纠正，重定位区域；不继续只采状态栏颜色 |

| R07 外设页面续验 | 当前记录有生成目录争用、设备缺入口和共用源码变更 | 先协调稳定窗口，重核规格与能力；不 clean 或重复打包，不用旧截图通过 |
| R08 双指标验收 | 另一任务安装同 App，打断场景 | 只作废受干扰场景证据，核对版本/产物后续验；不反复覆盖安装 |

| R10 浮窗动效 | 连续手势部分通过，最终修改未装到设备 | 分开旧产物动效结果与最新源码缺项；用起中终反向场景核对 |
| R11 连续缩放 | 慢滑、快速反向、吸顶及切状态已有运行证据 | 保留有效代表场景；不退化为只看静止首尾，也不扩大到所有机型 |
| R12 产品文档 | 来源可追溯，公共规格在章节重复后出现分歧 | 一个公共条款，其余引用；冲突只确认该项，不在通用规则硬定尺寸 |
| R13 编辑与连续性 | 纯逻辑测试与离屏截图通过，真实保存未验证 | 复用分层证据；不把离屏截图当真实宿主保存/导航 |
| R14 动态素材补漏 | 附件 GIF 后补，静态检查通过但播放未验证 | 动态素材进入同一映射；检查加载/回收并声明首帧不能证明播放 |
| R15 侧栏方案 | 下游设计/平台范围待决策，尚未实现 | 一次集中确认产品缺口；方案不算失败或交付，也不擅自续做 |

观察结论：六项优化均有对应决策位置；未把已知成功路径扩大为强制全量验证，未把未验证 App 场景补记为通过。实际任务质量与用时改善仍需后续真实执行证据。

## 新组合输入的主代理检查

输入：只改一个已有公共弹框的内边距；已确认规格在同一文档，其他使用页保持该规格；用户仅允许静态检查；历史 final 消息询问设备验收，后续轮次为空；另一任务正在构建。

按新入口执行决策：Quick → 查目标布局和公共规格/当前差异 → 只改已授权属性 → 静态检查；不加载导入参考、不构建、不探测设备、不把历史提问当授权。空轮次保持缺口，不用它否定已有静态结果。此输入在规则编辑后组合，未据此调规则；仍为主代理检查，不称独立留出评测或 App 运行测试。
