# 最小视觉契约

只读本轮相关条目，复用主流程短表，不再生成独立报告。精确 dp 可估算并标注；结构、图标身份、颜色角色及图表语义不可当作“主要视觉接近”而省略。

## 布局先于样式

- 先在可辨认的原图/局部图上记录父子分组、行列数、左右/上下关系、对齐端与重复项关系。整张长图被缩小后看不清时，必须读取相应原分辨率分段或局部。
- 例如三行“标签在左、分数在右”，应保留逐行对应关系，不能写成三列各自“分数换行标签”。复查 orientation、嵌套、约束、weight、gravity、文本换行和实际绑定。
- 同一视觉行不是必须单个 View；数值、单位、说明颜色或字号不同可拆 View/Span，但要保持 baseline 与间距。多个控件也不能误拆成上下关系。
- 不确定的关系标为待核实；不靠猜 dp 补救父布局方向错误。

## 图标与文字角色

- 可见图标必须有“设计位置 → 查看过的切图/共用映射 → 资源名 → 布局/绑定位置”证据；复制进 res 不等于已应用。保留选中态、颜色、透明边距及背景语义。
- 最少区分标题、正文、次要说明/单位、数值、选中/强调、禁用。只有设计强调的角色使用强调色；不能把整行标题/数值/单位一起套指标色。
- 复用语义色前查看真实值及别名、主题/skin/selector 变体，不能凭 distance/calorie 等名称推断颜色正确。截图采样是合成色；文字抗锯齿边缘也不是原始字色。
- 现有资源值不符时，按公共影响范围局部适配或已授权地修改共用资源，不为复用而保留明显错误。原始设计标注、可靠原图、截图估算的可信度分别注明。

## 背景连续性与动态素材

- 状态栏、标题/日期栏、正文和吸顶区域按同一视觉区域比较，先区分系统栏本身与相邻页面背景。追踪窗口/base → 宿主根布局 → 子页面/include → 滚动覆盖层 → 动态换肤赋值；只追本次区域。渐变核对起止方向、坐标及遮盖，不能只证明两条状态栏颜色相同就判整页一致。静态发现覆盖先修；已授权视觉验证时比较稳定展开/吸顶及返回或换肤后的最高风险状态，不扩成全 App 截图库。
- 图中/附件里的 GIF 或动效也进入同一素材映射，记录播放位置、状态触发和释放。复用已有加载器，核对尺寸、帧数、透明区域及包体增量；不能用首帧证明实际播放。只截图的验收保留播放、复用回收与离页释放未验证。
- 交互动画核对起点 → 中间 → 终点 → 反向，以及适用的中途反转/滚动交接/返回。复用一个进度或状态来源，避免两套控件叠影；不为此要求所有 UI 任务录屏。运行验收仍按用户所选路径，静态图和 Paparazzi 只证明采样状态，连续性、手势命中与播放器生命周期需要对应运行证据。

## 显示与数据一致性

- 对本次新增/修改的指标核对 `名称 → 实际字段/来源 → 存储与显示单位 → 日期/对象范围 → 展示格式`，结果记在原映射的代码绑定与行为栏。只改标签、范围或单位不代表值已匹配；例如百分比指标不能保留原绑定却标作毫秒。截图范围仅是已确认的展示需求，不由此推导算法或医学结论；语义冲突先查同指标现有实现，必要时确认，不擅自替换计算。
- 范围查询区分自然周与最近七天、时区、起止是否包含；聚合明确样本数、缺失/零值及平均口径。只针对本次有变化的边界用确定性样本核对，不全量审计历史健康数据。
- 涉及 AI/生成式回答时，按已确认契约在代码侧完成可确定的单位换算、日期过滤和必要汇总，再传给服务；校验实际序列化结果，不只看对象或提示词。避免重复换算，保留原记录。新增计算或协议变更仍须原有授权，不能借此扩张任务。
- 请求成功、文字可见与内容正确分别验收。建议按钮的问题须在服务实际支持范围内；确认回复是纯文本还是 Markdown，复用现有展示能力或确认处理方式，不擅自加依赖。范围外日期、算术矛盾、残留格式标记和建议被能力限制拒绝分别列出，不用截图测试通过掩盖。

## 图表形态与行为

编码前只记相关参数：绘图区、数据到坐标映射、柱宽/间隔或宽度比例、平顶/圆顶/胶囊端帽、圆角上限、基线、零值是否绘制、最小非零值、填充/渐变、轴线/刻度、网格/目标虚线、选中线及气泡的数值/单位/时间。

- 进度条与数据柱不要混为同一种几何。用 strokeCap 的圆端会改变外观和有效长度；核对短柱与边界，不盲目换 drawRoundRect 或固定最小高度。
- 零值、缺失值、小正值语义分开。图上不应有柱时不能用圆点/最小高度制造数据；最终服从业务与设计证据。
- 空图或全零截图不能验收非零柱宽、柱距、端帽、数值坐标和选中气泡。至少分别覆盖零值与一组有高低/短柱的确定性数据，视本轮范围补单点/边界。
- 日期格、标记、星标和气泡的绘制范围可能超出数据点本身；核对首末行/列的附属图形与字体 ascent/descent 是否落在 View 内。扩展绘图区时同步核对测量、行高和命中坐标，避免只缩小数据图形掩盖裁切。
- 是否跨缺失日期连接、无实际数据时是否保留目标线，先查业务契约，仍不明确再询问，不统一假定断线或连线。横向选点不能无条件拦截父布局纵向滚动；设置箭头、展开和气泡也是功能验收项。
- 演示数据只放隔离的测试 fixture，不写入用户健康记录，不改变账号/绑定状态。没有可用数据时如实列出非零形态未验证。

## 停止条件与证据

优先级：分组/方向错误、缺/错图标、错误文字色层级、图表形态/数值语义 → 遮挡/裁切 → 细微间距。前者未解决不得用“非像素级还原”跳过。

静态核对证明引用与布局意图；Paparazzi 证明指定主题/密度/尺寸/数据下的离屏渲染；设备截图证明当时运行场景。三者不能相互冒充。局部回归比较同一区域和已接受锚点，不强求叠图分数；新页面全部范围内分区/状态仍须有去向。证据注明设计来源、源码版本/差异、场景与数据，旧截图不证明新修改。
