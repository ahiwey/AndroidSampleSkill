# 必要度量

复用命令结果和 manifest，不为统计新增昂贵系统。
记录可获取的下载/复用/缺项数、版本是否核实、取材/构建/验收耗时及重复读取或返工原因。
没有可靠 Token 计量写 unavailable，不估造节省比例。
已实现、空页、未验证分开，资源下载数不算业务完成数。
发现重复下载、大 JSON 入上下文、无效轮询和反复询问时针对原因改进。
快速达标即停止，不要求全状态视觉评分。

同条件比较：固定输入/哈希、范围、质量门和环境，分别记录冷启动与缓存命中耗时、读图次数、工具调用/输出量、返工数。无同条件基线不报节省比例；输出字符数不是 Token。漏验收或质量下降的更短流程不算提效。

维护任务摘要工具时可运行 `python -B -X utf8 tests/benchmark_task_review.py`：合成同一输入，对比原始 JSON 输出与有界投影的 30 次暖运行中位数，另记新 CLI 冷启动；先断言纠正、空轮次、历史范围和未安装边界保留。只输出哈希、环境、字符数和耗时，不落用户历史。结果仅衡量 JSON 处理/输出，不推导 Agent 或 App 全流程提速；入口字数减少也单独报告为加载体积变化。
