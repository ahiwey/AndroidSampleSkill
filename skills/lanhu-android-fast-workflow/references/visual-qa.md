# 轻量验收

默认检查本轮页面：可打开/返回、主要数据与空态合理、图片正确、无明显遮挡、新入口可达。
先静态核对新增路由及参数，再在可运行时走一遍主要链路。相同模板只截代表页和有明显布局差异的状态，不逐画板重截；剩余未运行路径明确列出。
优先修错页、无响应、错数据、缺图、主要区域比例和图标背景；仅细微边距、字形或阴影不同可交付，不自动进入连续精修。
已有设备状态仍有效时复用；只有首次选择验收路径或环境变化才运行探测器，不每改一个文件就重新探测。

```powershell
powershell -NoProfile -File scripts/visual_qa_router.ps1 -ProjectRoot "<project>" -Scope interaction
```

路由只探测，不安装、不构建、不操作手机：
- 有真机优先，仍须项目授权、实际解锁及可用数据。
- 无真机：孤立布局优先已有 Paparazzi；集成、列表、生命周期优先已有 Roborazzi。
- 无适用现成工具输出 unverified，不默认新增依赖或新建测试工程。
- 已有模拟器仅作为明确允许的降级，不自动创建。
- 不为截图伪造健康数据、改用户账号或绑定状态。

## 构建

复用覆盖当前修改的 APK；确需最终安装才在一批修改后启动一次最窄 assemble。源码已变化不能用旧 APK 宣称新实现通过。
若该次构建已覆盖所需资源或编译检查，不再补跑同范围任务；项目强制检查仍执行。
先查任务存在、设备可用、APK 是否过期和实际活跃构建；空闲 daemon 不算。
单次最终安装构建默认最多 600 秒，项目更严限制优先，用户可显式授权本次覆盖。
窄编译/资源任务仍按项目预算。路由输出预算，但不负责自动执行或超时取消。
限制并发，不 clean、不停止共享 daemon。较长有界等待并保持必要进度更新，不频繁轮询全日志。
日志保留到已确认目录，只返回成功摘要或首个关键错误。
超时只取消自身进程，不自动重跑或绕过构建配置。设备临时设置记旧值并恢复。

## 精修才启用

用户要求高度还原或指出局部问题时，固定相关视口、主题、语言、数据和滚动位置。
返工先看最新局部证据、实际资源及父布局再修改；有可用设备时同场景复核并回归关联锚点，不连续猜 offset，也不扩大成全页面重做。
可按需用 ImageDiff.java 定位差异；分数不是业务验证，资源合成图不是 App 截图。
达标停止，不自动升级全状态/全语言回归。

交付区分：代码完成、编译通过、已安装运行、视觉检查、数据受限。
空页只验证打开与返回，不宣称内容、保存或同步完成。
