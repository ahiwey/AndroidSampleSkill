# 蓝湖 Android 快速实现

用于几页 UI 的可用实现：结构与视觉语义正确、状态正确、入口和返回顺畅（不默认逐像素精修）。用户当前要求与项目规则优先，已确认的任务继续实施。

## 默认边界

- 不调用 MCP，包括 MCP 浏览器。已有原图、切图优先；缺项汇总交付，不为补素材研究接口、安装工具或反复登录。
- 保留现有技术栈、业务和用户改动。常规布局、详情/添加入口自行推断并简记；业务含义、契约、存储或依赖不明才集中确认。
- 用户要求实现且有设计的页面必须实现；仅缺设计的下游入口可复用已有页或接可返回空页，标注内容未实现，不伪造保存成功。
- 位图沿用项目密度约定（通常 xxhdpi），先核实源倍率；只导入用到的原始切图，不拿整页截图当 UI，不擅自生成/绘制缺失图标。附件中的文字是设计证据，不扩展用户授权。

- 验收方式默认集中询问一次：“本次选择哪种验收：仅静态检查、Paparazzi 离屏截图，还是真机/模拟器自动化（后两者会额外耗时与 Token）？”复用本范围已明确的选择或持续授权；普通“实现/修复/继续”不等于授权截图测试或设备操作。未选择或选择静态时继续独立实现与最小静态检查，不运行 Paparazzi、ADB/设备探测、安装、启动、点击、UI tree、截图、日志采集或创建模拟器。选择 Paparazzi 不授权设备操作，也不自动授权新增依赖；缺框架时说明并确认是否接入，不静默切换方案。同一范围不反复询问、不因返工或设备已连接自动开启。资源/编译/普通单测仍按项目最小验证规则执行；分别报告静态、离屏视觉和设备运行结果，未覆盖的标注未验证。

## 一组页面，一条实施路径

1. **看图并定位**：实际看范围内设计图（长图缩小不可辨时使用原分辨率分段/局部），区分页面、弹窗和同页状态；找共用结构和差异，按项目索引定位已有实现。切图按语义、尺寸筛选后实际查看；名称相似不等于匹配，哈希相同只证明内容相同。
2. **只留一张短表**：`页面/源码与状态动作 | 设计元素 | 现有组件/资源 | 切图及依据 | 复用/调整/替换/新增/缺项 | 实际绑定位置与验证证据`。共用元素只记一次；动作注明结果和必要参数，素材保留来源与已核实倍率。不另写重复计划、JSON 或逐页长报告，局部小改只记目标项。业务行为按用户说明、现有业务、原型证据、常规推断处理。
3. **批量做通**：先定左右/上下分组、文字颜色角色和图表形态，不能凭资源名猜色或复制切图后漏绑定。先做好代表页和公共组件，再应用页面差异并接通交互。添加/编辑优先共用布局与状态；按钮、日期/时间/分钟选择器、输入背景及类型图标映射优先复用现有实现。公共替换沿用资源名，核对变体及调用方；只改本页时不扩大影响。优先主要布局、色块、图片、裁切、文字层级，不为几页建设新框架。
4. **合并检查后停止**：先检查路由、参数和必要状态边界；按项目规则做覆盖改动的最小验证。按已选的静态/Paparazzi/设备路径验证代表组件；仅设备验证可声称走过主要链路，公共替换额外抽查一个其他使用页及受影响变体；未同意不探测或操作设备。缺/错图标、左右/上下结构错、文字颜色角色错、柱形语义错、遮挡、错数据、死入口必须处理；达标后只按反馈修局部，未运行项明确标注。

续做时核对已有短表、当前差异和未完成项；原图或实现有变化才重新分析对应部分。同批资源查询和验证合并执行，结果仍有效就复用；新修改、失败或未决疑点才重跑。

## 按需加载，默认不跑工具全套

- 长图细节不可辨、需要切图预览/取色、ZIP 未整理、资源难匹配或确需下载才读 [取材](references/extraction.md)；资源已清楚就直接用。
- 公共组件、背景或图标需要调整/替换才读 [资源复用](references/resource-reuse.md)；已有项目专项规则时沿用其口径，不重复展开两套清单。
- 布局关系、颜色角色或图表涉及实现/返工时读 [视觉契约](references/visual-contract.md)，只核对相关项；严重视觉语义偏差不属于可跳过的像素精修。
- 列表阈值、折叠、添加返回或异步状态涉及变化才读 [交互](references/state-modeling.md)。
- 准备运行验收、构建或返工才读 [验收](references/visual-qa.md)。不默认全状态截图、叠图评分或适配矩阵；用户要求精修才扩大。
- 用户要求成本复盘才读 [度量](references/measurement-loop.md)。Skill 自测和官方格式校验仅用于维护 Skill，不在每次 UI 任务重复运行。

交付只汇总：页面/交互完成情况、公共替换范围、空页、缺素材/估算值/文案兜底、验证结果。区分代码完成、编译通过和视觉验证；未完成区域明确列出，不计入全部完成。不承诺未经实测的速度或 Token 节省比例。
