# 蓝湖 Android 快速实现

用于几页 UI 的可用实现：主要视觉接近、状态正确、入口和返回顺畅。用户当前要求与项目规则优先，已确认的任务继续实施。

## 默认边界

- 不调用 MCP，包括 MCP 浏览器。已有原图、切图优先；缺项汇总交付，不为补素材研究接口、安装工具或反复登录。
- 保留现有技术栈、业务和用户改动。常规布局、详情/添加入口自行推断并简记；业务含义、契约、存储或依赖不明才集中确认。
- 用户要求实现且有设计的页面必须实现；仅缺设计的下游入口可复用已有页或接可返回空页，标注内容未实现，不伪造保存成功。
- 位图默认 xxhdpi，确认源倍率；只导入用到的原始切图，不拿整页截图当 UI，不擅自生成/绘制缺失图标。

## 一组页面，一条实施路径

1. **看图并定位**：实际看范围内原图；找共用结构和差异。同页的折叠、连接、布局切换优先作为状态，不按画板数量建页面。按项目索引定向找现有实现。
2. **只留一张短表**：`页面/源码位置 | 状态或动作 → 结果（必要参数） | 所需资源/缺项`。用它指导实现和交付，不另写重复计划、JSON 或逐页长报告。行为按用户说明、现有业务、原型证据、常规推断处理；冲突涉及业务才问。
3. **批量做通**：先做好代表页和共用的颜色、卡片、标题栏，再应用到其余页并接通跳转与返回。大块布局、主要色块、真实图片、图标背景/裁切、文字层级优先；非关键间距、字体、阴影可近似。复用项目现成组件，不为几页建设新框架。
4. **合并检查后停止**：先检查路由、参数和必要状态边界；按项目规则做覆盖改动的最小验证，避免同批修改反复编译安装。有已授权可用真机则走主要链路、看代表页；无设备用已有适用工具，不能运行就标未验证。明显缺图、遮挡、错数据、死入口必须处理；达标后只按反馈修局部。

续做时核对已有短表、当前差异和未完成项；原图或实现有变化才重新分析对应部分。

## 按需加载，默认不跑工具全套

- ZIP 未整理、资源难匹配或确需下载才读 [取材](references/extraction.md)；资源已清楚就直接用。
- 列表阈值、折叠、添加返回或异步状态涉及变化才读 [交互](references/state-modeling.md)。
- 准备运行验收、构建或返工才读 [验收](references/visual-qa.md)。不默认全状态截图、叠图评分或适配矩阵；用户要求精修才扩大。
- 用户要求成本复盘才读 [度量](references/measurement-loop.md)。Skill 自测和官方格式校验仅用于维护 Skill，不在每次 UI 任务重复运行。

交付只汇总：页面/交互完成情况、空页、缺素材或估算值、验证结果。缺项影响的区域应明确降级，不宣称视觉已完成。
