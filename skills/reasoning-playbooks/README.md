# 常见 Prompt：推理与决策方法

`reasoning-playbooks` 提供 12 种常用推理与决策方法，可显示菜单、执行指定方法，或为问题自动选择最少且最有价值的方法。

## 快速使用

显示方法菜单：

```text
常见Prompt
```

让 Skill 自动选择方法并直接回答：

```text
常见Prompt：比较方案 A 和方案 B
```

指定第 9 种方法：

```text
常见Prompt 9：比较方案 A 和方案 B
```

要求先推荐合适方法，再直接执行：

```text
常见Prompt 推荐：帮我判断这个技术方案
```

也可以显式调用：

```text
使用 $reasoning-playbooks，通过事实核查验证这条技术说法。
```

## 十二种方法

| 编号 | 方法 | 适合解决的问题 |
| --- | --- | --- |
| 1 | 苏格拉底式提问 | 需求含糊时，追问一个会改变实现、结论或验收的关键问题。 |
| 2 | 双层解释法 | 先用生活化例子解释，再给出准确机制、边界和误区。 |
| 3 | 反向拆解 | 从优秀范例反推目标、结构、关键选择和可迁移规律。 |
| 4 | 横纵分析法 | 纵向分析历史路径，横向按统一维度比较对象。 |
| 5 | 事实核查 | 分离事实、推断和价值判断，核查来源、时间与上下文。 |
| 6 | 专家视角会诊 | 用三个互补专业视角分析共同事实、分歧和综合方案。 |
| 7 | 第一性原理 | 区分事实与惯例假设，从真实目标和约束重新推导。 |
| 8 | 跨领域借解 | 从远领域寻找结构相似的机制，并转化为低成本实验。 |
| 9 | 双向钢人论证 | 分别提出双方最强论证、适用条件和风险，再明确判断。 |
| 10 | 最小实验 | 选择最关键假设，设计低成本、可逆且有停止条件的实验。 |
| 11 | 隐藏天赋探索 | 从具体经历探索能力、兴趣和能量模式，不作固定标签。 |
| 12 | 人生设计 | 生成三条明显不同的路径，并用访谈或短期体验验证。 |

## 路由规则

- 只输入 `常见Prompt`、`常见 Prompt` 或 `思考菜单` 时，只显示菜单，不擅自展开。
- 指定编号或方法名称时，直接使用该方法。
- 使用“推荐”或不指定编号的问题形式时，选择最可能改变结果的最少方法，并简短说明原因。
- 简单、明确的问题不会机械叠加多种方法。
- 事实、推断、价值判断和建议会分开表达；证据不足时标记为未核实。
- 专家视角默认在当前回答中完成，不自动创建子代理。
- 方法 11 和 12 只有在用户明确要求自我探索时启用，不作为心理诊断。

完整触发与执行规则见 [SKILL.md](./SKILL.md)。
